# Protocol — Human-in-the-Loop Review

Mandatory for disciplinary or high-stakes academic decisions. Implements [[01_false_positives_non_native]], [[05_external_evidence]], [[04_mixed_texts]], [[README]] warnings.

## When mandatory
- Any recommended grade penalty or misconduct process
- Non-native writer flagged
- Arabic text evaluated with weak tools
- Mixed-authorship likely
- Uncertainty medium/high
- Only commercial score available

## Reviewer checklist
1. Read student work for mastery (ideas, specifics, course fit).
2. Compare to **baseline writing sample** if exists.
3. Request **version history** / draft trail (Google Docs, Word).
4. Prefer **oral defense** or short rewrite under supervision for disputed sections.
5. Check citations for fabrication (SEM-002) — content integrity, not “AI vibes.”
6. Discount pure style tells (em dash, polish) especially for L2 writers.
7. Document rationale; enable **appeal** path.
8. Never paste detector % as proof of cheating alone.

## Allowed outcomes
| Outcome | Action |
|---------|--------|
| Educational conversation | Teach citation/AI policy; no punishment |
| Process concern with evidence | Proceed with multi-factor case file |
| Clear | Close flag; log FP if detector fired |
| Inconclusive | No penalty; optional learning support |

## Institutional recommendations (from gaps)
- Independent appeals committee
- Local tool audit before procurement
- Focus deterrence + culture + verification over “perfect detector”
- Deterrence: clear AI use policy + process transparency
