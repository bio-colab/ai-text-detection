# fn-Planning — Multi-step action plans

**Role:** Generate plans for detection cases, research, and system maintenance.

## Plan types

### 1. Case investigation plan (per text)
```
1. Context card ([[fn-Context Building]])
2. Perception multi-sensor ([[fn-Perception]])
3. Pattern + relation pass
4. If Arabic → Arabic plan branch
5. If short → non-statistical emphasis
6. If mixed suspected → segment scores
7. Fuse ([[protocol-Signal Fusion]])
8. If uncertainty high or stakes high → [[protocol-Human Review]]
9. Request external evidence (version history, oral)
10. Decide + log memory
```

### 2. Arabic capability plan (from gap 03)
1. Build Arabic Human+AI corpus (Jais/AceGPT + student essays)
2. Fine-tune AraBERT / MARBERT classifier
3. Define Arabic stylistic markers (connectors, structures)
4. Prefer semantic + external over EN statistical
5. Never ship EN commercial as AR truth

### 3. Institutional integrity plan (from README next steps)
1. Read gaps 03 + 01 first
2. Arabic AI Text Corpus project
3. Simple AR classifier
4. External evidence layer (version history parser)
5. Refresh package every 6 months

### 4. Living taxonomy plan (gap 08)
- Quarterly: arXiv survey sweep
- Demote expired style markers
- Re-benchmark ensemble on local samples
- Update [[queue-Priorities]]

### 5. Ensemble upgrade plan
Target stack: Binoculars + Fast-DetectGPT + TTR + watermark z + external + human
